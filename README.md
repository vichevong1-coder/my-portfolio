# Personal Portfolio

A modern, responsive personal portfolio built with Next.js, React 19, Tailwind CSS v4, and Framer Motion.

## Tech Stack

- **Framework:** Next.js (App Router)
- **UI & Animations:** React 19, Tailwind CSS v4, Framer Motion, Lucide React
- **Theming:** next-themes
- **Language:** TypeScript

## Getting Started

First, run the development server:

```bash
bun dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build & Deployment

Build for production:

```bash
bun run build
# or
npm run build
```
